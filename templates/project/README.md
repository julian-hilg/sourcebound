# Example Study: Fat Tails in Daily EUR/USD Returns

Working repository (private). The public repository is generated by `sb publish`
from `public/README.md` and the allowlist in `project.yaml`.

```sh
sb run          # analysis -> figures -> bibliography -> data appendix -> PDF -> checks (= make all)
sb check        # ledger, citations, results, contracts
sb publish      # build dist/public + dist/data and run the publication gates
```

Status: `sb status`. Research log: `log.md`. Rules for agents: `AGENTS.md`.
